# M4.3.4.2 — Adapter Foundation Implementation

**Status:** Implementation prepared; local Bench test acceptance pending.  
**Branch:** `feat/m4.3.4.2-adapter-foundation`  
**Parent design:** [M4.3.4.1 Runtime Adapter Contract and Implementation Plan](M4.3.4_RUNTIME_ADAPTER_CONTRACT_AND_IMPLEMENTATION_PLAN.md)

## Delivered

The new `dt_master.runtime_adapters` package establishes the common foundation:

- `contracts.py`: versioned request/result dataclasses, supported runtime/method/outcome vocabularies, strict JSON compatibility checks, bounded 64 KiB request/result payloads, diagnostic validation and rejection of secret values, caller-provided commands, script paths, Docker endpoints/context, privilege flags and raw Compose text.
- `base.py`: common runtime adapter invocation boundary, capability checks, request/adapter identity binding, result/target correlation checks and fail-closed mutation guard requiring operation identity plus lease assertion/heartbeat callbacks. Mutation requests must match the active worker context.
- `registry.py`: trusted in-process registration, duplicate/invalid registration rejection, explicit adapter resolution by runtime and optional adapter ID, ambiguity rejection and capability inventory.
- `test_contracts.py`: pure contract, registry and invocation tests.

## Deliberate limitations

- No Host or Docker concrete adapter is registered yet. Those are M4.3.4.3 and M4.3.4.4.
- No mutation is enabled by this foundation.
- No public API, operation type, worker dispatch, target authorization or DocType was changed.
- The registry is populated only by trusted application code; user payloads cannot supply Python import paths or register adapters.
- Bench Environment target authorization remains deferred to M4.3.6. The current coordinator continues to accept only Infrastructure Node targets.
- Docker Compose deployment remains M4.3.5.

## Test command

Run from the bench root:

```bash
bench --site dhanatechnologies.local run-tests \
  --module dt_master.runtime_adapters.test_contracts
```

Then run the existing operation foundation regression:

```bash
bench --site dhanatechnologies.local run-tests \
  --module dt_master.operations.test_registry
bench --site dhanatechnologies.local run-tests \
  --module dt_master.operations.test_coordinator
```

The test results must be reported from the local Bench run before M4.3.4.2 is accepted.
