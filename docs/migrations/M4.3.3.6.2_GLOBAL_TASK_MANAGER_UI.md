# M4.3.3.6.2 — Global Desk Task Manager Component

**Status:** Submitted for local acceptance  
**Branch:** `feat/m4.3.3.6.2-global-task-manager-ui`  
**Base:** `develop`

## Objective

Provide a persistent Desk-wide panel for viewing active and recently completed Infrastructure Operations from the authorized snapshot API introduced in M4.3.3.6.1.

## Implementation

- Adds `dt_master/public/js/task_manager.js` and registers it through `app_include_js`.
- Adds `dt_master/public/css/task_manager.css` and registers it through `app_include_css`.
- Creates one singleton panel across Desk navigation.
- Loads bounded active/recent operation snapshots from `dt_master.api.operations.get_operations`.
- Supports minimized and expanded presentation; the preference is stored locally and does not affect operation execution.
- Displays operation type, target, execution state, safe error summary and lifecycle timestamp.
- Uses DOM text nodes/textContent for all server-provided values.
- Does not expose cancel/retry controls, fabricated percentages, payloads, diagnostics, or execution ownership.

## Scope boundary

This package is the initial snapshot and panel layer. Socket.IO event subscription, sequence deduplication, missed-event replay and reconnect reconciliation are reserved for M4.3.3.6.3. The browser remains a presentation client; the operation record and worker are authoritative.
